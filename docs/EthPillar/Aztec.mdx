## Running a Node

Aztec Sepolia Sequencer is a privacy-first Layer 2 on Ethereum, built for home and solo stakers.

Welcome to the **Aztec Sequencer Node Plugin**, a seamless integration for EthPillar designed to empower individuals and small operators to run an Aztec Layer 2 node with ease, security and full control. Whether you're an Ethereum enthusiast, a solo staker or a privacy advocate, this plugin gives you everything you need to participate in the Aztec network's testnet and beyond.

  <img src={useBaseUrl('img/EthPillarAztec.jpg')} />
</figure>

## 🚀 Key Features

- **Automated Setup & Configuration**  
  Simple install scripts to set up Docker, dependencies, and fetch the latest Aztec node client. Edit your `.env` and you're ready to launch.

- **Health Checks & Troubleshooting**  
  Built-in menu and scripts verify node health, RPC connectivity, disk usage, and environment configuration. Clear error messages and guided troubleshooting help ensure smooth operation.

- **Validator Registration & Role Claiming**  
  Step-by-step instructions and menu screens guide you through validator setup, ZKPassport humanity verification, and role upgrades (e.g., Guardian role).

- **Security Hardening**  
  - Runs as a non-root user (rootless Docker)  
  - Drops all unnecessary Linux capabilities, only allows essential networking  
  - Enforces strict memory limits and log rotation  
  - Uses `no-new-privileges` to prevent escalation  
  - Containerized for isolation and control

- **Logging & Monitoring**  
  Integrated with EthPillar's logging tools. Real-time logs, resource usage, and error reporting for proactive node management.

- **Backup & Recovery**  
  Easy validator key backup options and portable configuration for migration or disaster recovery.

## ⚡ Requirements: What you'll need
- **Operating System**: Ubuntu Server or Desktop 24.04.3 LTS (or newer)
- **Disk**
   - **Remote RPC**: 100GB NVMe SDD for Aztec Node
   - **Local RPC**: 850GB+ for Full Node Setup (execution L1 RPC + consensus beacon RPC + aztec L2)
- **Hardware**: 2 core / 4 vCPU, 16GB RAM, 25 Mbps network connection
- **Validator Funding**: At least 0.0001 SepoliaETH for testnet validator registration

## 📦 Quick Start

1. Open a terminal window from anywhere by typing `Ctrl+Alt+T`.

To install EthPillar, paste the following:

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/mjkeating/EthPillar/main/install.sh)"
```
<!-- Previous URL: https://raw.githubusercontent.com/coincashew/EthPillar/main/install.sh -->

2. To launch EthPillar, type::
```sh
ethpillar
```

3. Use the down arrow keys to select **Aztec L2 Sequencer**, and then press **OK**: 


<figure>
  <img src={useBaseUrl('img/AztecConfiguration.png')} />
  <figcaption>Aztec Node Configuration</figcaption>
</figure>

:::tip
Docker will install if missing. You may need to log out and log in again. Type `ethpillar` again to resume the install.
:::

4. Select **LOCAL** or **REMOTE** RPC

<figure>
  <img src={useBaseUrl('img/AztecRPCConfiguration.png')} />
  <figcaption>Selecting Local or Remote RPC</figcaption>
</figure>

If you select REMOTE, then provide your BEACON and ETH RPC URLs
	- Type URLs, for example https://beaconRPC.example.com or http://192.168.1.123

<figure>
  <img src={useBaseUrl('img/AztecRPCURL.png')} />
  <figcaption>Typing RPC URL</figcaption>
</figure>

If you select LOCAL, then EthPillar installs a **Nimbus+Nethermind** full node.
	- Select **Sepolia** as network
	- Answer **Yes** to start syncing now
	- Answer **Yes** to autostart when the system boots up
	- Nimbus+Nethermind full node will require 2+hrs to sync on a system with fast NVME ssd drives

5. Congrats! Aztec Sequencer is now installed.

<figure>
  <img src={useBaseUrl('img/AztecMenu.png')} />
  <figcaption>Aztec Menu</figcaption>
</figure>

## ⏭️ Next Steps:

1\. **Review `.env` Configuration**: Update values (for example, your ETH addresses/keys) if desired

2\. **Start Aztec Sequencer**: Ensure that Sepolia Full Node is fully synced first! This can take at least a few hours. Run the Health Checks.

<figure>
  <img src={useBaseUrl('img/AztecStart.png')} />
  <figcaption>Starting Aztec Sequencer</figcaption>
</figure>

3\. **Backup Aztec Validator Key**: Use the 🔐 menu option

4\. **Port Forwarding:** Forward the P2P port (default: 40400) to your local node IP address. Configure in your router.
