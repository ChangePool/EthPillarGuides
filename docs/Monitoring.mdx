You can create a graphical dashboard to monitor an Ethereum node that you operate using the following open source software solutions:

* [Prometheus](https://prometheus.io/docs/introduction/overview/) collects time-series data—metrics—from applications and infrastructure using a pull model, facilitating continuous system monitoring as well as alerting.
* [Prometheus Node Exporter](https://github.com/prometheus/node_exporter) enables exporting system hardware and operating system metrics for a host computer using Prometheus.
* [Grafana](https://grafana.com/docs/grafana/latest/) is an observability platform that facilitates visualizing data Prometheus collects.

### 1. Install Prometheus and Node Exporter

```bash
sudo apt-get install -y prometheus prometheus-node-exporter
```

### 2. Install Grafana

```bash
sudo apt-get install -y apt-transport-https
sudo apt-get install -y software-properties-common wget
sudo wget -q -O /usr/share/keyrings/grafana.key https://apt.grafana.com/gpg.key
```

```bash
echo "deb [signed-by=/usr/share/keyrings/grafana.key] https://apt.grafana.com stable main" | sudo tee -a /etc/apt/sources.list.d/grafana.list
sudo apt-get update && sudo apt-get install -y grafana
```

### 3. Enable Services To Start Automatically

```bash
sudo systemctl enable grafana-server prometheus prometheus-node-exporter
```

### 4. Create a Prometheus Configuration File

Remove the default **prometheus.yml** configuration file and edit a new one.

```bash
sudo rm /etc/prometheus/prometheus.yml
sudo nano /etc/prometheus/prometheus.yml
```

Choose the tab for your consensus client. Paste the following configuration into the new `prometheus.yml` file.

To save the `prometheus.yml` file and exit nano, press `Ctrl+X`, then press `Y`, and then press `ENTER`

Update file permissions.

```bash
sudo chmod 644 /etc/prometheus/prometheus.yml
```

Restart the services.

```bash
sudo systemctl restart grafana-server prometheus prometheus-node-exporter
```

Verify that the services are running.

```bash
sudo systemctl status grafana-server prometheus prometheus-node-exporter
```

### 6. Create an SSH Tunnel to Grafana

Each time you want to access Grafana, create an SSH tunnel with port 3000 forwarded.

<Tabs>
<TabItem value="x" label="Linux or MacOS" >
Example creating an SSH tunnel in Linux or MacOS:

```bash
ssh -N -v <user>@<staking.node.ip.address> -L 3000:localhost:3000

#Full Example
ssh -N -v ethereum@192.168.1.69 -L 3000:localhost:3000
```
</TabItem>

<TabItem value="w" label="Windows" >
Example creating an SSH tunnel in Windows using [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html):

In the left pane, expand the **Connection** branch, then expand the **SSH** branch, and then click **Tunnels**. In the right pane, type **3000** in the **Source Port** field, then type **localhost:3000** in the **Destination** field, and then click the **Add** button.

<figure>
  <img src={useBaseUrl('img/PuTTY.png')} />
</figure>

To save your configuration, in the left pane click the **Session** branch. In the right pane, type a unique descriptive name in the **Saved Sessions** field, and then click the **Save** button.

To open a connection, click to select the session to open in the list of saved sessions, and then click the **Open** button.

</TabItem>
</Tabs>

Now you can access Grafana on your local machine by pointing a Web browser to [http://localhost:3000](http://localhost:3000/)

### 7. Set Up Grafana Dashboards

1\. Using a Web browser, navigate to [http://localhost:3000](http://localhost:3000)

2\. To log in to Grafana for the first time, type **admin** in the **Email or Username** field, then type **admin** in the **Password** field, and then click the **Log In** button.

3\. When prompted, change your password.

4\. Click the **configuration gear** icon, then **Add data Source**

5\. Select **Prometheus**

6\. Set **Name** to **"Prometheus**"

7\. Set **URL** to [http://localhost:9090](http://localhost:9090)

8\. Click **Save & Test**

9\. Download and save the JSON file supporting your consensus client:

* [Lighthouse](https://raw.githubusercontent.com/Yoldark34/lighthouse-staking-dashboard/main/Yoldark_ETH_staking_dashboard.json)
* [Teku ](https://grafana.com/api/dashboards/13457/revisions/2/download)
* [Nimbus ](https://raw.githubusercontent.com/status-im/nimbus-eth2/master/grafana/beacon_nodes_Grafana_dashboard.json)
* [Prysm ](https://raw.githubusercontent.com/GuillaumeMiralles/prysm-grafana-dashboard/master/less_10_validators.json)

:::info

10\. Download and save the JSON file supporting your execution client:

13\. Add the consensus client dashboard via **Upload JSON file**

16\. Repeat steps 12 to 15 for the execution client dashboard

17\. Repeat steps 12 to 15 for the Node Exporter dashboard

:::warning
:fire: **Troubleshooting common Grafana issues**

**Symptom 1**: Your dashboard is missing some data.

**Solution 1**: Ensure that the execution or consensus client has enabled the appropriate metrics flag.

```bash
cat /etc/systemd/system/execution.service
cat /etc/systemd/system/consensus.service
```

* **Geth**: --http --metrics --pprof
* **Besu**: --metrics-enabled=true
* **Nethermind**: --Metrics.Enabled true
* **Erigon**: --metrics
* **Reth**: --metrics 127.0.0.1:9001
* **Lighthouse**: --validator-monitor-auto
* **Nimbus**: --metrics --metrics-port=8008
* **Teku**: --metrics-enabled=true --metrics-port=8008
* **Lodestar**: --metrics true

**Symptom 2**: You do not want to use SSH tunnels. You want to expose port 3000 to access Grafana, but understand the security concerns.

**Solution 2**: Open port 3000 in your UFW firewall. Access grafana at **http://\<NodeIPAddress>:3000**

```
sudo ufw allow 3000
```
:::

### 8. Set Up Alert Notifications

Get notified of problems with your validators. Choose between e-mail, Telegram, Discord or Slack.

<details>

<summary>Option 1: E-mail Notifications</summary>

1. Visit [https://beaconcha.in/](https://beaconcha.in)
2. Sign up for an account
3. Verify your **email**
4. Search for your **validator's public address**
5. Add validators to your watchlist by clicking the **bookmark symbol**.

</details>

<details>

<summary>Option 2: Telegram Notifications</summary>

1\. In Grafana, click the **Alerting** menu

2\. Click the **Contact Points** menu, and then click the **+Create contact point** button

3\. Give the contact point a **name**

4\. Select **Telegram** from the Integration list

5\. To complete the **Telegram API settings**, a Telegram channel and bot are required. For instructions on setting up a bot with `@Botfather`, see the topic [Bots: An introduction for Developers](https://core.telegram.org/bots#6-botfather). You need to create a bot API token.

6\. Create a new telegram group.

7\. Invite the bot to your new group.

8\. To initialize the group, type at least one message into the group.

9\. Visit [`https://api.telegram.org/botXXX:YYY/getUpdates`](https://api.telegram.org/botXXX:YYY/getUpdates) where `XXX:YYY` is your bot API Token.

10\. In the JSON response, find and copy the **Chat ID**. Find the **Chat ID** between **chat** and **title**

:::info
_Example of Chat ID_: `-1123123123`

    ```
    "chat":{"id":-123123123,"title":
    ```
:::

11\. Paste the **Chat ID** into the corresponding field in **Grafana**.

12\. **Save and test** the notification channel for your alerts.

13\. Now you can create custom alerts from your dashboards. For more details, visit the topic [Configure Alert Rules](https://grafana.com/docs/grafana/latest/alerting/create-alerts/).

</details>

<details>

<summary>Option 3: Discord Notifications</summary>

1. In Grafana, click the **Alerting** menu
2. Click the **Contact Points** menu, and then click the **+Create contact point** button.
3. Give the contact point a **name**.
4. Select **Discord** from the Integration list.
5. To complete the set up, a Discord server with an available text channel, as well as a Webhook URL are required. For instructions on setting up a Discord Webhook, see the topic [Intro to Webhooks](https://support.discord.com/hc/en-us/articles/228383668-Intro-to-Webhooks).
6. Copy and paste the Webhook URL into the Discord notification settings panel.
7. To push a confirmation message to the Discord channel, click **Send Test**
8. Now you can create custom alerts from your dashboards. For more details, visit the topic [Configure Alert Rules](https://grafana.com/docs/grafana/latest/alerting/create-alerts/).

</details>

<details>

<summary>Option 4: Slack Notifications</summary>

1. In Grafana, click the **Alerting** menu
2. Click the **Contact Points** menu, and then click the **+Create contact point** button.
3. Give the contact point a **name**.
4. Select **Slack** from the Integration list.
5. For instructions on setting up a Slack's Incoming Webhooks, see the topic [Sending Messages Using Incoming Webhooks](https://api.slack.com/messaging/webhooks).
6. Copy and paste the Slack Incoming Webhook URL in the **URL** field.
7. To push a confirmation message to the Slack channel, click **Send Test**
8. Now you can create custom alerts from your dashboards. For more details, visit the topic [Configure Alert Rules](https://grafana.com/docs/grafana/latest/alerting/create-alerts/).

</details>
