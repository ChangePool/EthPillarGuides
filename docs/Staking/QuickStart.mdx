## Recommended For Most Users

😄 **Friendly Node Installer**: EthPillar helps you deploy a systemd installation with minority clients Nimbus-Nethermind or Teku-Besu stack in just minutes. MEVboost included. Lido CSM supported.

:floppy_disk: **Ease of use**: No more need to remember CLI commands. Access common node operations via a simple text user interface (TUI). When EthPillar is deployed, operating your node becomes a breeze.

:owl: **Fast Updates**: Quickly find and download the latest consensus/execution release. Less downtime!

## :arrow_forward:  Ubuntu One-line Installation

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/mjkeating/EthPillar/main/install.sh)"
```
